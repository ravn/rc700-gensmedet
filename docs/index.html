RC700 Gensmedet

 

Gensmedet (Danish: reforged) is an open-source project to recreate the complete firmware for the Danish Regnecentralen RC702 Z80 micro-computer from scratch in C, and to advance the LLVM/Clang Z80 backend until it produces smaller code than SDCC.

The RC702 ("RC Piccolo") was produced from 1980 by Regnecentralen in Copenhagen. It ran CP/M 2.2 on a Z80 at up to 4 MHz with 64 KB RAM, one or two 5¼″ floppy drives, a CRT terminal, and SIO/PIO serial and parallel ports.

All four production firmware components now compile cleanly with Clang and produce smaller binaries than the reference SDCC toolchain:

  • autoload-in-c — 2 KB boot PROM (ROA375) that decompresses the system from floppy
  • rcbios-in-c — full CP/M BIOS in C with SIO, PIO, FDC and CP/NET SNIOS support
  • cpnos-in-c — CP/NOS slave PROM1 line-program (fits in a single 2 KB EPROM)
  • cpnet — CP/NET SNIOS for the BIOS (dual PIO/SIO transport, self-modifying dispatch)

The project also drives improvements to the ravn/llvm-z80 GlobalISel Z80 backend, which is a fork of zlfn/llvm-z80.

Project components

autoload-in-c — boot PROM ROA375

The RC702 boot PROM decompresses the CP/M system from floppy into RAM on power-up. The C rewrite fits in a 2 KB hard-capped EPROM (no A11 bridge on the hardware). The compressed payload is decoded by a split ZX0 decoder arranged around the 0x0066 NMI vector. Build with make clang; the boot gate test drives a real floppy image through MAME and verifies the A> prompt.

rcbios-in-c — CP/M BIOS

A complete reimplementation of the RC700 CP/M BIOS in C with inline assembly only where the Z80 architecture requires it. Clang produces a 629 B smaller binary than SDCC (5462 B vs 6091 B, −10.3%). Supports IOBYTE, SIO-B console mirroring, and the CP/NET SNIOS dual-transport interface.

cpnos-in-c — CP/NOS slave PROM1

CP/NOS is Regnecentralen's CP/NET slave operating system. This C rewrite targets a single 2 KB EPROM in PROM socket 1 and auto-selects between PIO-B (IRQ-driven, 256 B ring) and SIO-A (38400 polled) based on DIP switch S03. The PolyPascal v3 regression test compiles and runs the PRIMES program through primes below 30 000 reliably in MAME.

CP/NET SNIOS

The BIOS includes a self-modifying JP-trampoline SNIOS that reads SW1 bit 2 once at cold-boot and patches the network I/O vectors to route to either the PIO or SIO transport. The PIO implementation uses Mode 1 interrupt-driven input with a 256-byte SPSC ring at IVT slot 17. The end-to-end test boots to CP/M, connects to a z80pack MP/M-NET master, mounts drives H: and A:–D:, and verifies a native PRIMES computation.

 

DIP switch SW1 (port 0x14)

All firmware components read SW1 consistently. MAME convention: “On” = bit cleared (default), “Off” = bit set.

BitSwitchUsed byMeaning
0S01rcbios, cpnos Console mode. On = SIO-B + keyboard input, SIO-B + CRT output. Off = local only.
1S02autoload PROM1 lineprog enable. On = check PROM1 signature after floppy-boot failure and jump to lineprog if found. Off = skip.
2S03cpnos, rcbios SNIOS CP/NOS transport. On = PIO-B IRQ-driven (recommended). Off = SIO-A 38400 polled.
3–6S04–S07— unused / reserved
7S08rcbios, MAME FDC clock Floppy size. On = 5.25″ mini (250 kbps). Off = 8″ maxi (500 kbps).
